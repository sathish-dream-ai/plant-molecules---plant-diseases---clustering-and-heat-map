| Overview | Description |
| :--- | :--- |
| **What the Project Is** | A machine learning pipeline that groups plant-based chemicals (phytochemicals) by their physical structure to see which diseases they can potentially treat. |
| **What It Does** | • Converts chemical formulas into readable digital data (Morgan fingerprints).<br>• Uses AI clustering (K-Means) to group similarly shaped molecules together.<br>• Uses neural networks to create a visual heatmap linking these chemical groups to specific diseases. |
| **Data Source** | Real-world data extracted from the **IMPPAT database** (Indian Medicinal Plants, Phytochemistry And Therapeutics). *No simulated data was used.* |
| **Results & Insights** | Successfully grouped **490 plant compounds** into **49 structural clusters** and mapped them across **87 diseases**.<br><br>💡 **Key Insight:** Revealed that chemically similar plant molecules often target the exact same diseases, which helps researchers discover new multi-target drug candidates faster. |
